Empat Pilar Teknologi PhantomCast Studio

Dirancang secara modular untuk menjaga penggunaan CPU di bawah 15% pada frame rate 30–60 FPS.

1. Vanish Mode & Pemicu Gestur/Audio

Rekam Clean Plate latar kosong atau aktifkan Auto Background Infill berbasis MediaPipe ImageSegmenter. Transisi menghilang 400ms aktif otomatis saat menahan pose jari huruf “V” selama 500ms (cooldown 2 detik) atau saat terdeteksi Double-Snap jari (2 impuls 2.5kHz–7kHz berdurasi <35ms dalam rentang 200–800ms via FFT 512).

2. Local VTuber Studio (.vrm / .png) & AR Filter

Dukungan drag-and-drop model .vrm (Three.js + @pixiv/three-vrm) dan .png (PNGTuber) langsung dari komputer. Pelacakan 478 titik FaceLandmarker dihubungkan ke Kalidokit untuk rotasi kepala, kedipan mata, dan sinkronisasi vokal mulut (aa, ih, ou, ee, oh), dilengkapi Cyber Visor 3D, Privacy Pixelate, dan Cinematic LUT Shader.

3. Real-Time Voice Changer DSP (<25ms)

Pemrosesan suara digital pada AudioWorkletProcessor menggunakan algoritma Modulated Dual-Delay (WSOLA) Pitch Shifter dan kaskade BiquadFilter Formant Shifter. Dilengkapi pemilih perangkat keluaran audio (setSinkId) untuk VB-Audio Virtual Cable dan tombol Mic Monitor independen.

4. Python Virtual Camera Bridge (WS:8765)

Layanan pendamping virtual_bridge.py menerima stream biner RGBA (1280x720) dari OffscreenCanvas melalui ws://127.0.0.1:8765, memotong kanal alpha via NumPy (frame[:, :, :3]) menjadi RGB24, lalu meneruskannya ke DirectShow Virtual Camera Windows.

Parameter Preset Voice Changer DSP

Konfigurasi WSOLA Dual-Delay Pitch Shifter (Jendela 15.0 ms / 720 sampel @ 48 kHz) dan BiquadFilter Formant EQ.
